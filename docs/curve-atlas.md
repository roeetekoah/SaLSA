# Full-series curve atlas

Browse the representative curve candidates selected for the 72 source rows. The [series-input table](../data/series-inputs.csv) links every numerical copy to its source hash, original condition, processing stage and association status. There are 128,511 numerical rows across these copies. The water-control candidate is included in the table; the five atlas views below show the salt series, including separate No Cycling records.

- [Copper series](../figures/series-atlas-cu.png)
- [Cobalt series](../figures/series-atlas-co.png)
- [Nickel series](../figures/series-atlas-ni.png)
- [Manganese series](../figures/series-atlas-mn.png)
- [Iron series](../figures/series-atlas-fe.png)

Every panel preserves the complete positive-q range and uses a symmetric logarithmic intensity axis to keep nonpositive processed values visible. No intensity offsets, normalization or fits are applied. Different panels can have different ranges and processing stages, so do not make absolute intensity comparisons. SVG versions accompany the PNGs.

These are **representative archived candidates**, not a new classified dataset or proof that each curve generated its worksheet value. Some rows have several candidate acquisitions, fitting editions or treatments. Those alternatives remain in [the evidence-link table](../data/evidence-links.csv) and its [field guide](evidence-links.md). The five-salt spacing figure still reports historical assignments at their stated evidence level.
