# Environment and reproduction

Observed: Python 3.13.13, NumPy 2.4.4, Matplotlib 3.10.9 on Windows. The calculation uses only those two third-party Python packages. Figure PDFs/SVGs and numerical CSVs are generated by Matplotlib/NumPy; no generative scientific images are used.

Run `python analysis/rebuild.py`, `python analysis/series_atlas.py`, `python analysis/graphical_abstract.py`, then `python analysis/verify.py`. The package uses relative paths and can run from any working directory. Outputs are written to `figures/`, `results/`. Rebuilding overwrites generated outputs, not curated inputs.


The numerical checks cover input integrity, spacing-table relationships, sample/background roles and the selected sensitivity calculation. They do not reproduce detector integration or historical nonlinear X+ fits. Image bytes can vary across software versions and platforms.
